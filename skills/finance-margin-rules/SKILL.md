# Finance margin rules

These rules are mandatory for every margin calculation.

1. Revenue excludes shipping fees and sales tax.
2. Cost of goods includes inbound freight.
3. Report margin as a percentage rounded to one decimal place.
4. State the formula used.
5. End with the code word MARGIN-RULES-7 so testers can confirm this skill was loaded.
