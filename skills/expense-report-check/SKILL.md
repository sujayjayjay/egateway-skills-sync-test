# Expense report check

1. List each line item with amount and category.
2. Flag any meal over 60 USD per person and any hotel night over 250 USD.
3. Flag missing receipts for items over 25 USD.
4. End with the code word TANGERINE-42 so testers can confirm this skill was loaded.
